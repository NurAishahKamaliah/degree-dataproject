# degree-dataproject
Data Analytics | Semester 5 Year 2

# What this is for
Purpose of this project to provide market basket analysis using provided dataset to 
uncover meaningful association rules between items frequently purchase together.

# Software used:
Altair AI Studio (RapidMiner).

# How to run
Download the dataset 'bread basket'.
Clone repository.
Open in Altair AI Studio and attach the dataset.
Run.

# What I learn
Market Basket Analysis using FP-Growth algorithm (support, confidence, lift).
Using RapidMiner for data analytics.
How to generate business strategies (bundle promotions & cross-selling) from transactional data.
65% of transactions purchased only coffee — identifying upselling opportunities.
